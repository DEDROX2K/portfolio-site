How it's made

  1. A rope made of thirteen points

    The cord is 12 segments of 8px, simulated with Verlet integration. Each point remembers only where it is and where it was a frame ago; the difference is its velocity. Every frame adds gravity, lets the points coast, and keeps the top one pinned to the ceiling.

  2. Stiffness is just repetition

    After moving, each pair of neighbours is pulled back to exactly 8px apart. Doing that once makes a rubber band. Doing it 20 times a frame makes a cord. That loop count is the Stiffness slider.

  3. Grabbing the knob

    On pointerdown the knob captures the pointer and the last point is pinned to it, offset by where you grabbed. You can pull it in any direction, but never further than the rope length plus the pull travel, so it feels like it's attached to something.

  4. It switches mid-pull

    Like a real pull switch, the lights change the moment you pass 70% of the travel, not when you let go. It re-arms once the cord comes back up, so one pull is always one switch. Let go and it springs back, using the Swing value to decide how long it keeps moving.

  5. One SVG path

    The rope is a single path with quadratic curves through the midpoints of the segments, so it never looks jointed. The knob is a real <button>, moved with a transform and rotated to the angle of the last segment.

  6. It sleeps when it's still

    The animation loop stops as soon as no point is moving more than 0.02px, so the cord costs nothing while it hangs there. Click, Enter or Space also pull it with a little tug, and L works from anywhere on the site. With reduced motion on, it skips the swing on load.

Build a lamp-style pull cord that toggles dark mode on my website, in plain JavaScript and CSS with no dependencies.

What it is
- A thin rope hangs from the top edge of the viewport, 24px from the right (12px on phones), with a small knob at the end: 16×24px, rounded, with a 4px accent-coloured dot near the bottom.
- The wrapper is position: fixed at the top and above the page content. Use a darker knob on dark themes.
- Pulling the knob toggles light/dark mode. Store the choice in localStorage and apply it as <html data-theme="dark">.

Physics (Verlet rope)
- 13 points: 12 segments of 8px each. Point 0 is pinned at (0, 0), and the knob sits on the last point.
- Store each point as { x, y, px, py }. Velocity is (x - px, y - py); there is no stored velocity.
- Every frame (dt capped at 33ms):
  1. Multiply each point's velocity by a friction factor: 0.985 normally, or a "damping" of 0.94 right after release.
  2. Add gravity: 1250 px/s² × dt².
  3. Run 20 constraint passes. Each pass re-pins point 0 and pulls every neighbouring pair back to 8px apart. Split the correction 50/50, except that the pinned top point and a grabbed knob don't move.
- The number of passes is the rope's stiffness: fewer passes make it stretchy, more make it rigid.
- Read gravity, damping, passes and pull travel from a config object every frame, so changes apply to the very next pull.
- Stop the requestAnimationFrame loop when no point has moved more than 0.02px in a frame (plus a few frames of grace after any interaction). Restart it on interaction. It should cost nothing while it hangs still.

Drawing
- Draw the rope as one SVG path in a 200×240 overflow-visible SVG centred on the anchor. Start with M at the anchor, then add a quadratic curve to the midpoint of each next segment, using each point as the control point, and end with L at the last point. That way the rope never looks jointed.
- Use stroke-width 1.5, round caps and a translucent ink colour (about 40% of the text colour).
- The knob is a real <button>. Position it with translate() at the last point and rotate it to the angle of the last segment (atan2), with transform-origin at its top centre.

Interaction
- On pointerdown on the knob:
  - call preventDefault and setPointerCapture;
  - remember the grab offset;
  - pin the last point to the pointer.
- Limit the pull to rest length + 26px of travel, in any direction, and keep the knob at least 4px below the anchor.
- Switch the theme the moment the pull distance passes rest length + 70% of the travel, like a real pull switch detenting mid-pull, not on release. Re-arm once it comes back within rest length + 6px, so one pull is one switch.
- On release, let it spring back using the damping factor.
- A click without a drag, Enter or Space also toggles, with a small upward tug: offset each point's previous y by (i / 12) × 12px.
- Add a keyboard shortcut "L" that clicks the knob when no input is focused.
- Keep aria-pressed and aria-label ("Turn the lights off" / "Turn the lights on") in sync with the theme. Give it a visible focus ring. Call navigator.vibrate(8) on toggle where supported.
- On load, give it a small swing (offset the previous x of each point by (i / 12) × 3px), but skip that when prefers-reduced-motion is on.

Expose window.PullCord = { config, defaults } so a settings page can tune gravity, damping, stiffness (passes) and travel live.
